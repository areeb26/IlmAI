# Icons for IlmAI Extension

This directory should contain the following icon files:

## Required Icons

- **icon16.png** - 16x16 pixels (toolbar icon, small)
- **icon32.png** - 32x32 pixels (Windows taskbar)
- **icon48.png** - 48x48 pixels (extension management page)
- **icon128.png** - 128x128 pixels (Chrome Web Store, installation)

## Design Guidelines

### Theme
- **Colors:** Use gradient from `#667eea` (purple-blue) to `#764ba2` (purple)
- **Style:** Modern, clean, minimalist
- **Symbol:** Book, notes, or crescent moon (representing "Ilm" - knowledge in Arabic/Urdu)

### Recommendations
- Use a simple, recognizable symbol
- Ensure icons are clear at all sizes
- Include subtle Urdu calligraphy element if possible
- Test on both light and dark backgrounds

## Creating Icons

### Option 1: Use Online Tools
- [Figma](https://figma.com) - Professional design tool
- [Canva](https://canva.com) - Easy icon creator
- [IconKitchen](https://icon.kitchen/) - Generate all sizes at once

### Option 2: Professional Designer
- Hire a designer on Fiverr or Upwork
- Provide the color scheme and concept
- Request SVG source files

### Option 3: AI Generation
- Use DALL-E, Midjourney, or Stable Diffusion
- Prompt: "Modern minimalist app icon for note-taking app, purple gradient, book symbol, clean design, flat style"

## Temporary Placeholder

For development purposes, you can use solid color squares:
- Create 16x16, 32x32, 48x48, and 128x128 PNG files
- Fill with the primary color `#667eea`
- Add white text "AI" in the center

## Installation

Once you have the icons:
1. Save them in this directory (`assets/icons/`)
2. Ensure filenames match exactly: `icon16.png`, `icon32.png`, `icon48.png`, `icon128.png`
3. Reload the extension in Chrome
